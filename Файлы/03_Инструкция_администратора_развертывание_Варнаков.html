1. ВВЕДЕНИЕ

Настоящий документ описывает процедуру установки, настройки и ввода в эксплуатацию информационной системы «Форум». Инструкция предназначена для системных администраторов и специалистов технической поддержки.

2. ТРЕБОВАНИЯ К АППАРАТНОМУ И ПРОГРАММНОМУ ОБЕСПЕЧЕНИЮ

2.1. Аппаратные требования (минимальные):

  • Процессор: 2 ядра (x86_64).
  • Оперативная память: 4 ГБ RAM.
  • Дисковое пространство: 20 ГБ свободного места (SSD рекомендуется).
  • Сетевой интерфейс: 100 Мбит/с.

2.2. Программные требования:

  • Операционная система: Linux (Ubuntu 20.04 LTS / Debian 11+ / CentOS 8+) или Windows Server 2019+.
  • Java Runtime Environment: JDK 17 или выше (OpenJDK рекомендован).
  • СУБД: PostgreSQL версии 13 или выше.
  • Веб-сервер (опционально): Nginx или Apache HTTP Server (для организации обратного прокси и SSL).

3. УСТАНОВКА ЗАВИСИМОСТЕЙ

3.1. Установка Java (на примере Ubuntu/Debian):

sudo apt update
sudo apt install openjdk-17-jdk -y
java -version  # Проверка версии (должна быть 17+)

3.2. Установка PostgreSQL:

sudo apt install postgresql postgresql-contrib -y
sudo systemctl status postgresql  # Проверка статуса службы

4. НАСТРОЙКА БАЗЫ ДАННЫХ

4.1. Переключитесь на пользователя postgres и войдите в консоль СУБД:

sudo -u postgres psql

4.2. Выполните SQL-команды для создания базы данных и пользователя приложения:

CREATE DATABASE forum_db WITH ENCODING 'UTF8';
CREATE USER forum_user WITH PASSWORD 'complex_password_here';
GRANT ALL PRIVILEGES ON DATABASE forum_db TO forum_user;
\c forum_db
GRANT ALL ON SCHEMA public TO forum_user;
\q

Внимание: Замените 'complex_password_here' на надежный пароль, соответствующий политике безопасности вашей организации.

5. РАЗВЕРТЫВАНИЕ ПРИЛОЖЕНИЯ

5.1. Создайте директорию для размещения приложения:

sudo mkdir -p /opt/forum
sudo chown $USER:$USER /opt/forum

5.2. Скопируйте файл приложения (например, forum-app.jar) в созданную директорию.

5.3. Создайте файл конфигурации application.properties в той же директории со следующим содержимым:

# Порт сервера
server.port=8080

# Настройки подключения к БД
spring.datasource.url=jdbc:postgresql://localhost:5432/forum_db
spring.datasource.username=forum_user
spring.datasource.password=complex_password_here
spring.datasource.driver-class-name=org.postgresql.Driver

# Настройки JPA/Hibernate
spring.jpa.hibernate.ddl-auto=validate
spring.jpa.show-sql=false
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.PostgreSQLDialect

# Настройки файлов uploads
spring.servlet.multipart.max-file-size=10MB
spring.servlet.multipart.max-request-size=10MB
file.upload-dir=/opt/forum/uploads

5.4. Создайте директорию для загружаемых файлов:

mkdir -p /opt/forum/uploads

5.5. Запуск приложения в ручном режиме (для тестирования):

java -jar /opt/forum/forum-app.jar --spring.config.location=file:/opt/forum/application.properties

Убедитесь, что в логах нет ошибок и приложение успешно подключилось к базе данных.

6. НАСТРОЙКА АВТОМАТИЧЕСКОГО ЗАПУСКА (SYSTEMD)

Для обеспечения работы приложения в фоновом режиме и автоматического старта при загрузке ОС создайте сервис systemd.

6.1. Создайте файл сервиса:

sudo nano /etc/systemd/system/forum.service

6.2. Добавьте следующее содержимое:

[Unit]
Description=Forum Application Service
After=syslog.target network.target

[Service]
User=root
WorkingDirectory=/opt/forum
ExecStart=/usr/bin/java -jar /opt/forum/forum-app.jar --spring.config.location=file:/opt/forum/application.properties
SuccessExitStatus=143
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target

6.3. Активируйте и запустите сервис:

sudo systemctl daemon-reload
sudo systemctl enable forum
sudo systemctl start forum
sudo systemctl status forum

7. НАСТРОЙКА ВЕБ-СЕРВЕРА (NGINX) И БЕЗОПАСНОСТЬ

7.1. Установка и настройка Nginx (Reverse Proxy):

sudo apt install nginx -y
sudo nano /etc/nginx/sites-available/forum

Конфигурация Nginx:

server {
    listen 80;
    server_name forum.yourdomain.com;

    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

Активация конфигурации:

sudo ln -s /etc/nginx/sites-available/forum /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx

7.2. Настройка брандмауэра (UFW):

sudo ufw allow 'Nginx Full'
sudo ufw allow 'OpenSSH'
sudo ufw enable

Прямой доступ к порту 8080 следует закрыть, оставив доступ только через Nginx (порты 80/443).

8. МОНИТОРИНГ И ОБСЛУЖИВАНИЕ

8.1. Просмотр логов приложения:

Логи выводятся в systemd journal:

journalctl -u forum -f

Либо проверяйте файл логов внутри приложения (если настроено логирование в файл).

8.2. Резервное копирование базы данных:

Рекомендуется настроить ежедневный бэкап с помощью cron:

0 2 * * * pg_dump -U forum_user forum_db > /backup/forum_backup_$(date +\%F).sql

9. УСТРАНЕНИЕ НЕИСПРАВНОСТЕЙ

  • Приложение не запускается: Проверьте логи (`journalctl -u forum`), убедитесь, что порт 8080 не занят другим процессом, проверьте права доступа к файлу .jar и конфигурации.
  • Ошибка подключения к БД: Проверьте логин/пароль в `application.properties`, убедитесь, что служба PostgreSQL активна (`systemctl status postgresql`), проверьте настройки `pg_hba.conf` (разрешение локальных подключений).
  • Ошибки 502 Bad Gateway: Убедитесь, что приложение работает и слушает порт 8080, проверьте конфиг Nginx на наличие опечаток.
