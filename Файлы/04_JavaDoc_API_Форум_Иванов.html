1. ОБЩАЯ ИНФОРМАЦИЯ

Данный документ описывает программный интерфейс приложения (API) для системы «Форум». Взаимодействие с сервером осуществляется посредством HTTP/HTTPS запросов в формате REST.

Базовый URL API:

  • Локальная разработка: http://localhost:8080/api
  • Продуктивная среда: https://forum.yourdomain.com/api

Интерактивная документация (Swagger UI):

Для удобного тестирования и изучения методов доступна интерактивная консоль по адресу:

  • http://localhost:8080/swagger-ui.html

Спецификация OpenAPI (JSON):

  • http://localhost:8080/v3/api-docs

2. АУТЕНТИФИКАЦИЯ И АВТОРИЗАЦИЯ

Большинство эндпоинтов API требуют аутентификации пользователя. Для доступа к защищенным ресурсам необходимо использовать JWT (JSON Web Token).

Получение токена:

Выполните POST-запрос на эндпоинт /auth/login, передав логин и пароль. В ответе сервер вернет токен, который необходимо использовать в заголовке всех последующих запросов.

Формат заголовка:

Authorization: Bearer <ваш_jwt_токен>

3. ОПИСАНИЕ ЭНДПОИНТОВ

3.1. Контроллер аутентификации (Auth Controller)

POST /api/auth/register

  • Описание: Регистрация нового пользователя.
  • Тело запроса (JSON): 
    {
  "username": "string",
  "password": "string",
  "email": "user@example.com",
  "role": "USER" 
}
  • Ответы:
    • 201 Created: Пользователь успешно создан.
    • 400 Bad Request: Ошибка валидации данных (например, слабый пароль или занятый email).

POST /api/auth/login

  • Описание: Вход в систему.
  • Тело запроса (JSON): 
    {
  "username": "string",
  "password": "string"
}
  • Ответы:
    • 200 OK: Возвращает объект с токеном доступа.
    • 401 Unauthorized: Неверный логин или пароль.

3.2. Контроллер тем (Topic Controller)

GET /api/topics

  • Описание: Получение списка всех тем с пагинацией.
  • Параметры запроса (Query Params):
    • page (int): Номер страницы (начиная с 0).
    • size (int): Количество элементов на странице (по умолчанию 10).
    • sort (string): Сортировка (например, createdAt,desc).
  • Ответы:
    • 200 OK: Список объектов Topic.

GET /api/topics/{id}

  • Описание: Получение полной информации о теме по ID.
  • Параметры пути: id (Long) — идентификатор темы.
  • Ответы:
    • 200 OK: Объект Topic.
    • 404 Not Found: Тема не найдена.

POST /api/topics

  • Описание: Создание новой темы. Требуется авторизация.
  • Тело запроса (JSON): 
    {
  "title": "Заголовок темы",
  "content": "Текст первого сообщения",
  "categoryId": 1
}
  • Ответы:
    • 201 Created: Тема создана.
    • 401 Unauthorized: Пользователь не авторизован.

PUT /api/topics/{id}

  • Описание: Обновление темы (заголовка или статуса). Доступно автору или модератору.
  • Ответы:
    • 200 OK: Тема обновлена.
    • 403 Forbidden: Недостаточно прав.

DELETE /api/topics/{id}

  • Описание: Удаление темы. Доступно модератору или администратору.
  • Ответы:
    • 204 No Content: Тема удалена.
    • 403 Forbidden: Недостаточно прав.

3.3. Контроллер сообщений (Post Controller)

GET /api/topics/{topicId}/posts

  • Описание: Получение списка сообщений внутри конкретной темы.
  • Параметры пути: topicId — ID темы.
  • Ответы:
    • 200 OK: Список объектов Post.

POST /api/topics/{topicId}/posts

  • Описание: Добавление нового ответа в тему. Требуется авторизация.
  • Тело запроса (JSON): 
    {
  "content": "Текст сообщения"
}
  • Ответы:
    • 201 Created: Сообщение добавлено.

DELETE /api/posts/{id}

  • Описание: Удаление конкретного сообщения.
  • Ответы:
    • 204 No Content: Сообщение удалено.

3.4. Контроллер пользователей (User Controller)

GET /api/users/{id}

  • Описание: Получение публичного профиля пользователя.
  • Ответы:
    • 200 OK: Объект UserDTO (без чувствительных данных).

PUT /api/users/profile

  • Описание: Обновление собственного профиля (имя, аватар, подпись). Требуется авторизация.
  • Ответы:
    • 200 OK: Профиль обновлен.

5. КОДЫ СОСТОЯНИЯ HTTP

  • 200 OK: Запрос успешно выполнен.
  • 201 Created: Ресурс успешно создан.
  • 204 No Content: Запрос выполнен успешно, тело ответа пустое (обычно при удалении).
  • 400 Bad Request: Ошибка валидации входных данных.
  • 401 Unauthorized: Отсутствует токен аутентификации или он неверен.
  • 403 Forbidden: Пользователь авторизован, но не имеет прав на выполнение действия.
  • 404 Not Found: Запрашиваемый ресурс не найден.
  • 500 Internal Server Error: Ошибка на стороне сервера.
