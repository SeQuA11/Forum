# ForumWeb - Веб-версия форума

Веб-клиент для форума, использующий REST API из проекта `api` и функционал из `forumD`.

## Структура проекта

```
ForumWeb/
├── index.html          # Главная страница
├── css/
│   └── styles.css      # Стили приложения
├── js/
│   ├── api.js          # API клиент (CRUD операции)
│   └── app.js          # Основная логика приложения
├── lib/                # Библиотеки (при необходимости)
└── README.md           # Документация
```

## Требования

1. **Запущенный backend API** на порту 8080
   - Проект `api` должен быть запущен
   - PostgreSQL база данных должна быть доступна
   - Порт: `http://localhost:8080`

2. **Веб-сервер** для статических файлов
   - Любой HTTP сервер (Nginx, Apache, или простой Python server)

## Быстрый старт

### 1. Запуск API сервера

```bash
cd /workspace/api
./mvnw spring-boot:run
```

API будет доступен по адресу: `http://localhost:8080`

Swagger документация: `http://localhost:8080/swagger-ui.html`

### 2. Запуск веб-клиента

#### Вариант A: Python HTTP сервер (для разработки)

```bash
cd /workspace/ForumWeb
python3 -m http.server 3000
```

Откройте в браузере: `http://localhost:3000`

#### Вариант B: Node.js http-server

```bash
npm install -g http-server
cd /workspace/ForumWeb
http-server -p 3000
```

#### Вариант C: Nginx/Apache

Настройте виртуальный хост для директории `/workspace/ForumWeb`

## Функционал

### Аутентификация
- ✅ Регистрация нового пользователя
- ✅ Вход в систему (JWT токен)
- ✅ Выход из системы
- ✅ Сохранение сессии в localStorage

### Категории
- ✅ Просмотр всех категорий
- ✅ Создание категории (только ADMIN)
- ✅ Фильтрация тем по категориям

### Темы
- ✅ Просмотр всех тем
- ✅ Просмотр тем по категории
- ✅ Создание новой темы
- ✅ Удаление темы (автор, модератор, админ)
- ✅ Модерация статусов (PINNED, CLOSED, HIDDEN)
- ✅ Счетчик просмотров

### Сообщения
- ✅ Просмотр сообщений темы
- ✅ Добавление ответов

### Ролевая модель
- **USER**: создание тем, ответы
- **MODERATOR**: управление статусами тем, удаление
- **ADMIN**: управление категориями, полное управление

## API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| POST | `/api/v1/auth/register` | Регистрация |
| POST | `/api/v1/auth/login` | Вход |
| GET | `/api/v1/categories` | Список категорий |
| POST | `/api/v1/categories` | Создать категорию (ADMIN) |
| GET | `/api/v1/threads` | Список тем |
| GET | `/api/v1/threads/{id}` | Тема по ID |
| POST | `/api/v1/threads` | Создать тему |
| DELETE | `/api/v1/threads/{id}` | Удалить тему |
| PATCH | `/api/v1/threads/{id}/status` | Изменить статус (MODERATOR+) |
| GET | `/api/v1/threads/{id}/posts` | Сообщения темы |
| POST | `/api/v1/threads/{id}/posts` | Добавить сообщение |

## Конфигурация

Измените `API_BASE_URL` в файле `js/api.js` если API находится на другом адресе:

```javascript
const API_BASE_URL = 'http://localhost:8080/api/v1';
```

## Тестирование

1. Зарегистрируйте первого пользователя через веб-интерфейс
2. Войдите под этим пользователем
3. Создайте категорию (если пользователь ADMIN)
4. Создайте тему
5. Добавьте ответ в тему

## Устранение проблем

### Ошибка подключения к API
- Проверьте, что API сервер запущен на порту 8080
- Проверьте CORS настройки в `SecurityConfig.java`
- Откройте консоль браузера (F12) для просмотра ошибок

### Проблемы с авторизацией
- Очистите localStorage браузера
- Проверьте правильность учетных данных
- Убедитесь, что JWT секрет совпадает с настройками API

### Темы/категории не загружаются
- Проверьте наличие записей в базе данных
- Убедитесь, что пользователь авторизован (для некоторых endpoints)
- Проверьте логи API сервера
